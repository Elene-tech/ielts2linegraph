# Module 1 · Line Graphs — інструкція

## Що в архіві
```
index.html            службова сторінка: готові iframe-коди для Kwiga (відкрий її на Vercel)
lessons/              один файл = один урок Kwiga (03–08) + vocabulary.html
shared/core.css       єдиний вигляд усіх уроків
shared/core.js        спільна логіка: вправи, прогрес, збереження відповідей, авто-висота
data/graphs.js        усі графіки (дані в одному місці)
data/lesson-XX.js     зміст уроків (вправи, пояснення, моделі)
data/vocab.js         словник (Основа / Додатково), один на весь модуль
shared/vocab.js       панель словника в кожному уроці
```

## Як розмістити
1. Відкрий репозиторій на GitHub → Add file → Upload files → перетягни **вміст** папки (index.html, lessons, shared, data). Папки перетягуються разом із файлами.
2. Commit changes. Vercel оновить сайт сам за ~1 хвилину.
3. Відкрий `https://ТВІЙ-САЙТ.vercel.app/` → там коди iframe для кожного уроку.
4. У Kwiga в кожному уроці: блок «HTML-код» → встав код.

Старі файли (01-…, 02-… у корені) можна лишити, поки не перепідключиш уроки. Нові лежать у папці `lessons/`.

## Як змінити вправу
Відкрий `data/lesson-03-introduction.js` (або інший) і правь текст. Код тут не чіпай. Кожен блок має тип: example, gap, choose, pick, rewrite, write, build.

## Збереження відповідей
- Автоматично в браузері учня (localStorage). Кнопка «📝 Мої відповіді»: скачати .txt, скопіювати, зберегти як PDF.
- Якщо браузер блокує сховище в iframe (private mode, деякі налаштування Safari), вправи працюють, але відповіді не переживуть перезавантаження. Тому в підказці учням радимо скачати файл.
